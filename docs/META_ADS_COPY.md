# Drafts and build notes (Oct 1–7)

Campaign "Grapejuice Co", ad set "Grapejuice Co - Broad". Eight ads, one per angle. Edit anything in place; I'll build the ads from whatever is in this file when you say it's final.

**How to edit**

- Pick **Option A or B** for each primary text (delete the other), or keep both and I'll use Meta's "multiple text options" so it tests them.
- Fill in **Image** with a filename from your image folder. Square (1:1) works everywhere; add a 9:16 version too if you have one for Stories/Reels.
- Length targets: primary text hook in the first ~125 characters (Meta truncates after that), headline 40 or fewer, description 30 or fewer.

**Facts every ad must stay true to** (from the site and box rules)

- $80 for the box with one kid; +$10 for each additional kid.
- In every box: candles, gelt, latke and sufganiyot mixes, wrapping paper, and an instruction booklet. Per kid: a dreidel, a book and a present.
- A menorah is **not** included (it's an add-on).
- Free shipping. Charged only when the box ships. Add-ons cost extra.
- Customize until Nov 7. Arrives by Nov 21. Hanukkah 2026 starts the evening of Dec 4.
- Limited quantity.

**Meta policy guardrails**

- Never assert or imply the viewer's religion, finances, or other personal attributes ("Are you Jewish?", "Interfaith family?", "On a tight budget?" all get rejected).
- Talk about the product and the holiday, not about who the viewer is.

**Tracking (added automatically to every ad):** `utm_source=meta&utm_medium=paid_social&utm_campaign=grapejuice-co&utm_content=<ad name>`

**Images** are in `/Untraditional/Ads/` as `ads_v1_NN.png`. Each ad uses a square (1080x1080) for Feed and a vertical (1080x1920) for Stories and Reels. The 1116x628 landscapes are 16:9 rather than Meta's 1.91:1, and the square covers those placements better, so they're unused. Proposed mapping below; swap freely.
