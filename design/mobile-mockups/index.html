Design system

One set of parts for every mobile page: type, colors, buttons, product tiles, fields, sheets and the sticky bar. Every page below is built from these.

Icons are placeholders. When building, keep the icons already on the site (the grapes logomark, the Rav icon, the favorite heart and the rest). Use the mockups for layout, color and type, not icon artwork.

Rules: one beige, one gold for lines, one dark gold for text, and one black (ink). Gold outlines mark only what's yours or selected. Primary buttons are black with gold text. Bottom bars are white, with the total and a black button. Button labels say where they go ("Checkout · $95", "Next: Note"). The lock date reads "Change anything until Nov 7" everywhere. Browsing pages use the site header, and every flow uses the task header. One box summary comes in two sizes. Tiles use main product photos, and heroes use secondary photos.
